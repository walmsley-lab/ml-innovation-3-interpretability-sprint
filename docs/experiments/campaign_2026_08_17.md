## 1. The headline, stated at the width the evidence supports

**Exploratory, seeds 0–2, three model scales.** Training on source `A` confers
an immediate zero-shot advantage on target capability `B`, measured at `t = 0`
before any `B` training, and it survives a **32× increase in non-embedding
parameters**.

| scale | params | A `t=0` | A′ `t=0` | BG `t=0` |
|---|---|---|---|---|
| 1× (d128, l4) | 786k | **0.126 ± 0.016** | 0.014 ± 0.004 | 0.021 ± 0.006 |
| 8× (d256, l8) | 6.3M | **0.157 ± 0.042** | 0.012 ± 0.007 | 0.017 ± 0.001 |
| 32× (d512, l8) | 25.2M | **0.097 ± 0.037** | 0.012 | — |

Chance is 0.0156. **A′ and BG sit at chance at every scale**; `A` sits 6–10×
chance with tight between-seed variance.

`A` and `A′` differ in exactly one property — whether a recurring entity keeps
its value — and are matched on unigram, bigram and positional statistics, on
entity recurrence rate, and on distinct-entities-per-document, all verified
against a same-stream null before any run (see §3).

The area-under-curve version of the same comparison is much noisier: +0.85
(1×), +0.40 (8×), −0.25 (32×, where A′ has n=1), effect/noise ≈ 1.9. **The
signal lives in the head start, not the acquisition rate**, which is what the
project's own `t=0` decomposition predicts (E6: head start 3–4× more
reproducible than its sum with the rate term).

### The threat to this result

`A` and `B` share the underlying computation by construction. `A` teaches "a
recurring entity keeps its value"; `B` queries exactly that. A `t=0` head start
is precisely what **direct task transfer** would produce, and it does not by
itself demonstrate developmental readiness.

The **C1 discrimination scout** is the test: an identical copy structure over a
**disjoint entity sub-pool** (`IND#h1` → `BIND#h2`, zero shared entity tokens,
verified). If the head start survives with no shared tokens, the transferred
thing generalizes across identity and is mechanism-level. If it collapses to
chance, this is content transfer and much less interesting.

**Until C1 resolves, this result must not be described as developmental
readiness.**

## 2. The candidate mechanism does not explain it

`M` — a per-head prefix-matching score measured **off-distribution** on random
repeated-token sequences, never on micro-world records — is **not selective to
`A`** at any scale.

| scale | A peak/M₀ | A′ peak/M₀ | BG peak/M₀ | selectivity A/A′ (gate ≥ 2.0) |
|---|---|---|---|---|
| 1× | 1.47 ± 0.04 | 1.49 ± 0.44 | **1.91 ± 0.85** | **0.96** |
| 8× | 4.15 ± 0.05 | 6.15 ± 3.89 | 3.02 ± 1.21 | **0.61** |
| 32× | 5.07 ± 1.48 | 5.52 (n=1) | — | **0.90** |

The V2 preflight showed a striking single-seed transient on `A`
(0.0284 → 0.1100 → 0.0370, 3.9× baseline, with A′ and BG flat). **It did not
reproduce.** At 1× — the same configuration — `A` peaks at 1.47× and `BG` peaks
highest of all three arms.

Two things follow.

**`M` scales strongly with capacity** (1.47 → 4.15 → 5.07), consistent with
induction-style circuits being a larger-model phenomenon, and an argument that
the 1× model was simply too small to host the mechanism.

**The `A_peak` statistic is biased.** Max-over-trajectory rewards noise: `BG`
has both the largest between-seed standard deviation (0.0241) and the largest
peak. This is a defect in V2.1 §2, introduced when the transient hypothesis was
written, and any replay or transition-window statistic must be robust to it.

So the current position is: **a real, scale-persistent, history-dependent
future-learning effect that our first candidate mechanism fails to explain.**

## 3. Apparatus results — the instrument, not the world

**The substrate audit rejected the first implementation.** Fresh-entity
sampling gave 2.88 vs 7.94 distinct entities per document, and short-range
predictors could separate the streams (unigram CE gap 0.0060 against a null
limit of 0.0030). A model could have exploited entity diversity instead of the
mechanism under test. Rebuilt as value-rebinding:

| control | A vs A′ gap | same-stream null limit |
|---|---|---|
| positional | 0.0003 | 0.0025 |
| unigram | 0.0005 | 0.0029 |
| bigram | 0.0009 | 0.0057 |
| distinct entities/doc | 2.89 vs 2.89 | — |
| **binding oracle** | **1.0000 vs 0.0153** | chance 0.0156 |

**P5 passes, on both CPU and GPU paths**: an uninformative `BG→BG` phase
boundary moves `B` accuracy by exactly 0.0000, ruling out optimizer/distribution
-shift artifacts at the boundary.

**Two design defects were found and repaired before any confirmatory run.** The
negative control `C` was vacuous — `FACT` was evaluated but never trained, so
"C did not move" tested nothing; with a `BIND+FACT` target it now reaches 0.510
at the frozen budget. And `B` nearly ceilinged at 0.861; the target budget was
recalibrated on dedicated seeds 900–901 to `TARGET_STEPS = 2000`, placing `BG`
mid-band at 0.516.

**Throughput.** The assumed bottleneck was wrong. Document generation costs
0.17 ms; the real costs were an un-jitted evaluator (185 ms) and a per-step
host-device sync. Both fixed, with the cached path verified **elementwise
identical** to the frozen online sampler across all six streams. 2.2× faster.

## 4. Lane B — closed, with a clean negative

The W/P substrate **cannot** support a behaviourally-matched latent-state test.
With the frozen overlap regime, the corrected common tail (T1) and a symmetric
2000-step budget, competence pass rate was **1/6**:

| history | W accuracy across seeds | P |
|---|---|---|
| `W_first` | 0.977 / 0.469 / 0.508 | ~0.99 |
| `P_first` | 0.293 / 0.258 / 0.238 | 1.000 |

`W` is only learnable when it receives a pure phase, which `P_first` never
provides, and `W_first` is itself seed-fragile in the way `docs/risks.md` §2b already
documents. Difficulty matching is a **gate, not a nicety** — the same lesson the
Layer-2 `t90` calibration encodes, relearned.

The question is not dead, only the substrate. The full pipeline — generation,
137 basis-invariant state features, hash-verified frozen analysis — is built,
validated and substrate-agnostic. It needs a host where two comparable skills
coexist. `BIND` and `FACT` are candidates: both learnable, difficulty-matched by
construction.

## 4b. The readiness-vs-transfer factorial (B₂)

The `t=0` head start is exactly what direct task transfer produces, so it
cannot by itself demonstrate readiness. Two crossed manipulations separate the
possibilities.

**Surface overlap** — disjoint entity sub-pools. `IND#h1 → …#h2` shares zero
entity tokens with its target; `IND#h2 → …#h2` shares them all. Verified
disjoint.

**Computation overlap** — a new target `B₂` (`BINDT`) = **retrieval ∘
transform**. Identical to `BIND` in template, clause count, query position and
answer marginal (entropy 4.1397 for both, against a uniform 4.1589); document
bodies are *elementwise identical*. The single difference is that the answer is
`π(value)` for a fixed global derangement `π`.

Because `π` has **no fixed points**, a model that retrieves the bound value and
emits it unchanged is wrong every time. Zero-shot transfer is therefore blocked
by construction, and any `A` advantage on `B₂` must appear as a faster
acquisition **rate**.

|  | same computation (`BIND`) | different computation (`BINDT`) |
|---|---|---|
| **shared surface** (h2→h2) | C1 scout | B₂ factorial, bench |
| **disjoint surface** (h1→h2) | C1 scout | B₂ factorial, w2 |

### How to read it

| pattern | reading |
|---|---|
| advantage only with shared surface **and** shared computation | ordinary task transfer; the effect is uninteresting |
| advantage survives disjoint surface, dies on `B₂` | transfer is computation-specific but identity-general — partial readiness |
| advantage survives on `B₂`, as a **rate** effect with `t=0` at or below chance | **readiness**: `A` changed future learnability without supplying the answer |
| `A` arm shows systematically **below-chance** `t=0` on `B₂` | direct evidence the retrieval circuit transferred while the output map did not — the cleanest available signature |

The last row is worth emphasising: below-chance is not noise here. It is what a
transferred-but-mismapped mechanism looks like, and it is only measurable
because `π` is a derangement.
